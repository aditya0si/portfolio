Standard technology logos come from the official `devicons/devicon` repository (MIT). Agent CLI marks come from each project's own repository or official site, except Codex, which uses the **shared OpenAI brand mark** (the official `developers.openai.com` favicon). That mark is not a Codex-specific mark and no glyph has been invented.
