2. **Execution Rating Protocol**: Wherever code, test definitions, CI configurations, or benchmarks exist in static git tree snapshots but were not executed during this audit session, runtime execution is explicitly rated **UNKNOWN (Unexecuted in snapshot)**.
3. Every claim is strictly anchored to registered Evidence IDs in `research/evidence-ledger.json`.
